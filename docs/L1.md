## แบบฝึกหัด: ./mvnw dependency:tree

| library / starter | มีไว้ทำอะไร |
|---|---|
| spring-boot-starter-test | Starter หลักของ Spring Boot ที่รวบรวมไลบรารีสำหรับการเขียนและรันการทดสอบ (เช่น JUnit Jupiter, AssertJ, Mockito) ที่มีรุ่นเข้ากันได้มาให้ครบในตัวเดียว |
| junit-jupiter | เฟรมเวิร์กหลัก (JUnit 6) สำหรับเขียนและรัน Unit Test ในภาษา Java โดยใช้แอนโนเทชัน เช่น `@Test` |
| assertj-core | ไลบรารีสำหรับเขียนคำสั่งตรวจสอบผลลัพธ์ (Fluent Assertions) ที่อ่านเข้าใจง่ายเป็นธรรมชาติ เช่น `assertThat(x).isEqualTo(y)` |
| mockito-core | ไลบรารีสำหรับสร้างวัตถุจำลอง (Test Double / Mock) เพื่อแยกส่วนของโค้ดที่ต้องการทดสอบออกจากส่วนประกอบอื่น |
| json-path | ไลบรารีสำหรับค้นหาและดึงข้อมูลจากโครงสร้าง JSON เพื่อใช้ตรวจสอบค่าในผลการทดสอบ |

## Reflection (2–3 ประโยคต่อข้อ)

1. red bar แรกพิสูจน์อะไร ที่ green bar อย่างเดียวพิสูจน์ไม่ได้
พิสูจน์ว่าชุดการทดสอบ (test) ที่เราเขียนขึ้นถูกเรียกใช้งานจริงและสามารถตรวจจับข้อผิดพลาดได้เมื่อโค้ดยังไม่ถูกต้อง (ล้มเหลวด้วยเหตุผลที่ตรงตามความคาดหมาย เช่น ค่าที่คืนมาไม่ตรงกับที่คาดไว้) หากเห็นแต่ green bar อย่างเดียวตั้งแต่แรก เราจะไม่สามารถมั่นใจได้เลยว่า test นั้นตรวจสอบเงื่อนไขได้จริงหรือแค่ผ่านตลอดเวลาโดยไม่ได้ตรวจจับข้อผิดพลาดเลย

2. ถ้าเครื่องของคุณหายวันนี้ จะกู้งานกลับมาได้จากที่ไหน
สามารถกู้งานทั้งหมดกลับมาได้จาก Remote Repository บน GitHub (`https://github.com/ten101popo/rottenpotatoes-6710301030`) โดยใช้คำสั่ง `git clone` ลงบนเครื่องใหม่ แต่มีเงื่อนไขสำคัญคือเราต้องสั่ง `git commit` เพื่อบันทึกการเปลี่ยนแปลงในเครื่อง และสั่ง `git push` เพื่อส่งประวัติ commit ล่าสุดขึ้นไปเก็บบน GitHub ไว้เรียบร้อยก่อนที่เครื่องจะสูญหาย
